Without the machinery#

Theme#

Dark and light, one global bit of state, without the flash of unstyled content.

Cross-widget update#

A distant widget reacts to an action elsewhere, without Context, a store, or an event bus.

Reacting to a change#

Running local code when another module changes, declared in the markup.

A list from data#

A list rendered from an array, without tearing the DOM on each change.

Live data#

A server stream into the interface, without a store adapter.

Forms#

Reading and validating a whole form, without controlled-input boilerplate.

Modals#

Nested, linked modals, with one view reused as the picker.
